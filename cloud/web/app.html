Notifications on this device

Get a push when an agent waits for your approval. Tapping it opens the approval page; approving still needs Face ID, a fingerprint or a security key (your passkey). The notification says only that something is waiting: no agent, action or recipient. Delivery is not guaranteed and not instant: everything that waits for you is always listed at the top of this Dashboard.

    Other notification channels

    For agents that work while you are away: get a message in Telegram, Slack or by e-mail when an agent waits for your approval. The message has only a link to the request (no agent, action or recipient); approving is still done on the approval page with your passkey. The token, webhook or address is stored encrypted and never shown again.

    Tool map

    How each MCP tool call of an agent becomes an action the witness judges. The server validates it when you save. Unknown tools are denied by default.

    Closed data

    Exact phrases (case-insensitive) that must never leave in the text of an action, by class. Plain literal matching: a paraphrase evades it. Classes you name here are the ones a mandate can forbid.
