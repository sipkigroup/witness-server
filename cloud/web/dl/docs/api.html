API

Base URL: https://witness.sipkigroup.com. JSON bodies, bytes are base64url without padding (*_b64), times are Unix seconds. Errors: {"error": "<CODE>", "detail": "..."}. A machine-readable description is in the OpenAPI file of the repository.

Agent API (Bearer key dwk_...)

callbodyanswer
POST /v1/actions{tool, args, client?}ActionResult
GET /v1/actions/{rid}?wait=0..25ActionResult (long poll while pending_approval)
POST /v1/actions/{rid}/present{}{result: accept|reject, reason} (consumes the receipt; call before executing)
POST /v1/actions/{rid}/report{executed: bool}{result: released|ignored}
GET /v1/witness{iss, alg, kid_hex, pub_hex, web_js_sha256}

ActionResult: {rid, verdict: allow|deny|defer|pass, reason, status, action, expires, aar_b64, proof, approval_url}. Repeating the same request while it is pending or approved returns the same action. For an allow the receipt aar_b64 is in the answer at once; GET /v1/actions/{rid} returns the inclusion proof.

Limits: 300 requests per minute per key, status reads (GET) counted in their own window (429 RATE_LIMIT, "slow down: N requests a minute per key; the call did not run"), 10000 actions per day per account and 4000 per agent (429 QUOTA), request body 256 KB (413 BODY_TOO_LARGE). Creating an agent needs a fresh passkey step-up (403 STEPUP_REQUIRED).

Python SDK:

from deus_witness import Witness
w = Witness("https://witness.sipkigroup.com", "dwk_...")
r = w.act("send_email", {"to": "bob@acme.example", "subject": "hi", "body": "..."})
if r.verdict == "allow" and w.present(r.rid)["result"] == "accept":
    ...   # do the thing
    w.report(r.rid, True)

Witness.act(..., verify=True) and the proxy check that the receipt belongs to the call that was sent. The TypeScript SDK does not verify receipts yet.

Web API (cookie dw_session; writes need Origin equal to the site origin)

Used by the dashboard; it needs a browser passkey.

  • Auth: POST /api/auth/register/begin|finish, login/begin|finish, logout; GET /api/me.
  • Agents: GET|POST /api/agents, PUT /api/agents/{id}/toolmap, DELETE /api/agents/{id}.
  • Mandates: POST /api/mandates/draft, POST /api/mandates ({mandate, envelope_b64}), GET /api/mandates.
  • Activity: GET /api/feed?agent_id=&before=&limit=, GET /api/budget, GET /api/approvals?status=pending, GET|POST /api/approvals/{rid}.
  • Export: GET /api/export (evidence pack zip; 6 per hour per account).
  • Health: GET /healthz -> {ok, ledgers, last_anchor_t}.

The signing envelope (wa-sig) and test vectors are in the contract folder of the repository.
