Project permissions

Shell commands you allowed for one project from an approval request ("Allow this command in this project"). Each one is an addition to the agent's mandate that you signed with your passkey: exactly these commands, only in that folder, until the date shown. Dangerous commands are never on this list: they are asked every time.

CommandsProjectAgentUntilUsedStatus

No project permissions yet. They appear here when you tick "Allow this command in this project" while approving a shell command.

Revoke takes one click and no passkey: ending a permission only narrows what the agent may do. It is recorded in your ledger; the next call of that command is asked again. A permission also ends when its date passes or when the agent's mandate is replaced or revoked.

Approvals for later runs

Calls you approved from an approval request with "Also approve this exact call for this agent's later runs". Each one is a passkey signature for this agent, this tool and exactly these arguments, under the mandate it was asked under, for the number of uses and until the time shown. Any other call is asked as usual.

CallAgentUntilUsedStatus

None yet. They appear here when you open "More options" on an approval and tick "Also approve this exact call for this agent's later runs" while approving.

Revoke takes one click and no passkey: the uses left are never applied, and the next such call is asked again. It also ends when its time passes, when its uses are spent, or when the agent's mandate is replaced or revoked.
