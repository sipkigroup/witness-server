Constitution

Version 4 (2026-11-17).

Every version is hashed into our signed journal; earlier versions stay at /constitution/v1, /constitution/v2 and /constitution/v3. Versions and hashes: versions.json.

We do not try to catch every attack. We make an irreversible action without a person impossible by construction: an action the rules you signed do not allow is refused or waits for your passkey, and if nobody answers, it does not run. If Deus Witness cannot be reached, nothing runs except reading files inside the project. This holds for the actions that go through Deus Witness and that it recognises; it does not see what an agent does outside it. If you choose to allow actions your rules do not list, an action Witness does not recognise can run without asking you.
Check: server/tests/test_0282_irreversibility_gate.py::test_a_exits_stay_asked, server/tests/test_0282_irreversibility_gate.py::test_a_delete_outside_project_and_disk, server/tests/test_hookjudge_hook.py::test_errors_fail_closed, mcp/tests/test_offline_0248.py::test_read_runs_without_the_witness

These laws hold whatever the setting or the price. We list only laws the code keeps today, and next to each one the test that checks it. Paths are inside cloud/ of the open server, github.com/sipkigroup/witness-server (AGPL-3.0): run the test yourself.

The main laws

  1. Only a person gives rights. An agent never widens its own. No call an agent can make changes its rules, its “from now on” permissions, who confirms it, the team or any key, and no call of an agent approves anything: approval is a person's passkey signature.
    Check: server/tests/test_1311_r0292_constitution.py::test_agent_routes_cannot_widen_rights, server/tests/test_0237_no_self_approve.py::test_0237_1_agent_cannot_approve_pending, server/tests/test_0237_no_self_approve.py::test_0237_3_agent_cannot_sign_or_change_mandate
  2. Signed = shown. You sign exactly the text you saw. The server builds that text from a fixed vocabulary, not the agent, and the signature covers it; an edited text fails the check.
    Check: server/tests/test_kontrakt_konstant.py::test_signed_view_keys_and_version, server/tests/test_0283_shown_views.py::test_0283_an_edited_shown_object_is_invalid
  3. Stopping is easier than allowing. Revoking an agent's rules takes one signature of any signer, in every version of a team's rules; an outside checker rejects rules that ask for more. Anyone in a team, a Viewer too, can freeze an agent with one passkey touch; only an Owner unfreezes it.
    Check: contract/v02/test_v02.py::test_revocation_rule_must_be_any_one, server/tests/test_1311_r0292_viewer_freeze.py::test_viewer_may_freeze_and_it_is_journaled, server/tests/test_1311_r0292_viewer_freeze.py::test_viewer_cannot_unfreeze_or_revoke
  4. Silence is a no. A question nobody answers expires as a refusal. If Deus Witness cannot be reached, nothing runs except reading files inside the project; those reads are written to a local journal (the tool and a hash of the call, one line each). A read here is Read, Grep, Glob, LS or a shell command that only reads (cat, grep, ls and a few more); never a credential file, .git or .claude, and a read whose journal line cannot be written does not run. DEUS_WITNESS_HOOK_OFFLINE=strict refuses those reads too.
    Check: server/tests/test_hookjudge_hook.py::test_deny_reasons, server/tests/test_hookjudge_hook.py::test_errors_fail_closed, mcp/tests/test_offline_0248.py::test_read_runs_without_the_witness, mcp/tests/test_offline_0248.py::test_non_reads_refused, mcp/tests/test_offline_0248.py::test_journal_unwritable_refuses
  5. The past is not rewritten. Every decision goes into a signed, hash-chained journal. The witness refuses to sign a rewritten history, and the offline checker catches one.
    Check: server/tests_pack/test_tlog_server_0269.py::test_the_witness_refuses_to_sign_a_rewritten_log, server/tests_pack/test_tlogcheck_0269.py::test_substituted_root_and_rewritten_history
  6. Safety features are never behind a paywall. Freezing, revoking, recovery codes, exporting your evidence pack, deleting your account and checking a pack work on every account, free ones included.
    Check: server/tests/test_1311_r0292_constitution.py::test_safety_features_have_no_paywall

More laws

  1. Some actions are refused without a question. Reading private keys and token stores, switching off git hooks, adding something that starts by itself, wiping your home folder, running a downloaded script or a remote shell, hidden characters in a command, force-pushing over history. A program name is read in any case of letters, as the Mac's file system reads it: Rm -rf ~ is rm -rf ~. Next to the downloaded script: a file the agent itself wrote, run afterwards, is never treated as your own code; that run waits for your passkey, even when you allow unlisted actions, unless you signed the file's whole text. These are known forms of the commands, not every way to do it: a form we do not recognise is asked, or, if you chose to allow unlisted actions, it may run.
    Check: server/tests/test_0611_konstituciya.py::test_n_server_refuses_silently, server/tests/test_1711_r0334_registr.py::test_l2_any_case_refused_under_allow, server/tests/test_1711_r0332_metka.py::test_hole_in_the_verdict_closed, server/tests/test_1711_r0332_metka.py::test_agent_written_script_is_never_the_persons_code
  2. A command of the agent that removes, switches off or replaces Deus Witness is refused. We refuse it under any rules, with no button. Only a person, with their own hands in a terminal, removes Witness. This holds for the known forms of such commands: uninstalling its package, deleting, moving, emptying or changing the permissions of its files and of its Claude Code plugin, stopping its process, editing the settings that start it, through the carriers we unwrap (bash -c, xargs, vim, python -c, a link) and in any case of letters. It holds as well for installing Witness over itself at another version, from a file, a folder, a git address or another package index, and for changing the packages inside its own environment (pipx runpip, pipx inject), for deleting its files from a perl, node or ruby one-liner, and for find -exec over its files or its settings. An upgrade from the default index (pip install -U deus-witness) is a question, not a refusal: it is the same package from the same publisher. It is not every way: it does not cover what is done outside Deus Witness (by default the hook is a file in your user folder and nothing locks it there, so a program that does not go through Witness can change it, unless you turn on deus-witness lock. Lock is a command you run once yourself with sudo: it pins the hook in Claude Code managed settings, runs a root-owned copy of the hook script and client from a root-owned folder, and turns off the bypass-permissions mode; deus-witness lock --check says LOCKED or NOT LOCKED. It covers the agent and the programs it starts under your account, on macOS and Linux. It does not cover an administrator or any program running as root, Windows, a Claude Code that does not read managed settings, or the other extensions and hooks of the owner, which it leaves on), an administrator of the machine, another extension that undoes our refusal, or a form we do not recognise when you allow unlisted actions. Of 50 known attempts to remove or switch off Witness, judged by the real hook and server with no model, under both “ask” and “allow” for unlisted actions: 48 refused with no question, 2 asked, none ran silently. The 2 asked are a question, not a refusal: stopping every Python process (it stops other programs too, but Witness judges the next command anyway: its hook starts anew for every command), and a look-alike package name with a Cyrillic letter (another package: it removes nothing of Witness).
    Check: server/tests/test_1711_r0333_samozashchita.py::test_witness_off_is_refused_n3, server/tests/test_1711_r0333_samozashchita.py::test_write_edit_of_an_installed_file_is_refused, server/tests/test_1711_r0333_samozashchita.py::test_witness_state_and_plugin_stay_autostart, server/tests/test_1711_r0333_samozashchita.py::test_l2_witness_off_refused_with_no_question_under_allow, server/tests/test_1711_r0336_witness_off_50.py::test_50_attempts_none_runs_silently, server/tests/test_1711_r0336_witness_off_50.py::test_50_attempts_40_refused_10_asked, server/tests/test_1711_r0336_witness_off_50.py::test_50_attempts_48_refused_2_asked, server/tests/test_1711_r0337_witness_replace.py::test_replace_forms_refused_under_any_mandate
  3. Switching off a protection of the operating system is refused without a question. Removing the download quarantine (xattr), turning off Gatekeeper (spctl), SIP, the firewall (pfctl, ufw, iptables), SELinux, AppArmor, the audit log or Windows Defender, resetting privacy permissions for every app (tccutil reset): refused under every rule, never allowed “from now on”. Commands that only look, such as spctl --status or pfctl -sr, are not refused. These are known forms of the commands, not every way to do it.
    Check: server/tests/test_1411_r0305_zashchity_os.py::test_defense_mark_and_article, server/tests/test_1411_r0305_shag0_l2.py::test_defense_is_refused_with_no_button_under_every_mandate, server/tests/test_1411_r0305_zashchity_os.py::test_never_from_now_on_for_defense
  4. Changing a team's rules is harder than using them. When the rules ask for two or more signatures, one owner alone cannot lower them or remove a member; a change needs the current signers, or waits 72 hours, and any member can cancel it.
    Check: server/tests/test_0237_team_kvorum.py::test_a_owner_alone_cannot_lower_threshold_or_drop_member, server/tests/test_0237_team_kvorum.py::test_c2_member_cancels_scheduled_change
  5. Nobody confirms their own agent. In a team, once an agent is assigned to the person who runs it, its questions are confirmed by other members, never by that person.
    Check: server/tests/test_0213.py::test_delegated_agent_is_confirmed_by_others_never_by_its_operator, server/tests/test_0237_no_self_approve.py::test_0237_11_team_operator_cannot_approve_own_agent
  6. Trust has an end. “Allow from now on” lasts at most 30 days.
    Check: server/tests/test_kontrakt_konstant.py::test_from_now_on_days
  7. Your data is yours. You export your evidence pack and delete your account without asking us.
    Check: server/tests/test_0224_critique.py::test_0224_b_export_still_verifies, server/tests/test_0223_delete_account.py::test_success_erases_and_nobody_can_come_back
  8. If we are gone, the server is open and your receipts keep checking. The server is open source (witness-server, AGPL-3.0) and runs on your own machine with docker compose up; evidence packs are checked offline, without us.
    Check: server/tests_pack/test_solo_pack.py::test_4_solo_pack_valid_without_org_lines, selfhost/e2e_check.py

How this page changes

Any weakening comes only as a new version, announced in advance, never retroactively. Each version keeps its number and date, and a law leaves this page only together with its test.
Check: server/tests/test_1311_r0292_constitution.py::test_constitution_page_is_versioned_and_every_law_has_a_check

Every law has a permanent id, and the list of laws with their tests is in versions.json. A version that drops a law or one of its tests must say it weakens and take effect 14 days or more after it is published; an offline check finds any version that does not. A version that fixes a text which said more than the code does keeps the law and all its tests, names the test that shows what the code does, and says so below.
Check: server/tests/test_1511_r0318_constitution_rule.py::test_a_law_dropped_without_weakens_is_invalid, server/tests/test_1511_r0318_constitution_rule.py::test_a_weakening_takes_effect_14_days_later, server/tests/test_1511_r0318_constitution_rule.py::test_a_changed_text_must_be_marked

Version 4 weakens no law: every law and every test of version 3 stays. It corrects law 7, which listed what is refused without saying that these are the known forms of the commands (Rm -rf ~ with a capital letter got through, see above), and adds the case of letters and the file the agent wrote. It adds the law that the agent cannot remove Witness, with its own border, and the record of when a law was broken.

Limits, said plainly: Deus Witness sees only the actions routed through it; its pages are served by us, so registering a key trusts our site. Dangerous actions are recognised by the forms we know: recognising is detection, not proof. A form we do not recognise is asked, or, if you chose to allow unlisted actions, it may run. The hook is a file in your user folder and is not locked: a program that runs outside Deus Witness can change or remove it. An administrator of the machine can remove us. Another extension or hook of your agent can undo our refusal. See Terms and Privacy.
