Constitution

Version 2 (2026-11-15).

Every version is hashed into our signed journal; v1 stays at /constitution/v1. Versions and hashes: versions.json.

We do not try to catch every attack. We make an irreversible action without a person impossible by construction: an action the rules you signed do not allow is refused or waits for your passkey, and if nobody answers, or Deus Witness cannot be reached, it does not run. This holds for the actions that go through Deus Witness; it does not see what an agent does outside it.
Check: server/tests/test_0282_irreversibility_gate.py::test_a_exits_stay_asked, server/tests/test_0282_irreversibility_gate.py::test_a_delete_outside_project_and_disk, server/tests/test_hookjudge_hook.py::test_errors_fail_closed

These laws hold whatever the setting or the price. We list only laws the code keeps today, and next to each one the test that checks it. Paths are inside cloud/ of the open server, github.com/sipkigroup/witness-server (AGPL-3.0): run the test yourself.

The main laws

  1. Only a person gives rights. An agent never widens its own. No call an agent can make changes its rules, its “from now on” permissions, who confirms it, the team or any key, and no call of an agent approves anything: approval is a person's passkey signature.
    Check: server/tests/test_1311_r0292_constitution.py::test_agent_routes_cannot_widen_rights, server/tests/test_0237_no_self_approve.py::test_0237_1_agent_cannot_approve_pending, server/tests/test_0237_no_self_approve.py::test_0237_3_agent_cannot_sign_or_change_mandate
  2. Signed = shown. You sign exactly the text you saw. The server builds that text from a fixed vocabulary, not the agent, and the signature covers it; an edited text fails the check.
    Check: server/tests/test_kontrakt_konstant.py::test_signed_view_keys_and_version, server/tests/test_0283_shown_views.py::test_0283_an_edited_shown_object_is_invalid
  3. Stopping is easier than allowing. Revoking an agent's rules takes one signature of any signer, in every version of a team's rules; an outside checker rejects rules that ask for more. Anyone in a team, a Viewer too, can freeze an agent with one passkey touch; only an Owner unfreezes it.
    Check: contract/v02/test_v02.py::test_revocation_rule_must_be_any_one, server/tests/test_1311_r0292_viewer_freeze.py::test_viewer_may_freeze_and_it_is_journaled, server/tests/test_1311_r0292_viewer_freeze.py::test_viewer_cannot_unfreeze_or_revoke
  4. Silence is a no. A question nobody answers expires as a refusal. If Deus Witness cannot be reached, the action does not run.
    Check: server/tests/test_hookjudge_hook.py::test_deny_reasons, server/tests/test_hookjudge_hook.py::test_errors_fail_closed
  5. The past is not rewritten. Every decision goes into a signed, hash-chained journal. The witness refuses to sign a rewritten history, and the offline checker catches one.
    Check: server/tests_pack/test_tlog_server_0269.py::test_the_witness_refuses_to_sign_a_rewritten_log, server/tests_pack/test_tlogcheck_0269.py::test_substituted_root_and_rewritten_history
  6. Safety features are never behind a paywall. Freezing, revoking, recovery codes, exporting your evidence pack, deleting your account and checking a pack work on every account, free ones included.
    Check: server/tests/test_1311_r0292_constitution.py::test_safety_features_have_no_paywall

More laws

  1. Some actions are refused without a question. Reading private keys and token stores, switching off the guard (git hooks), adding something that starts by itself, wiping your home folder, running a downloaded script or a remote shell, hidden characters in a command, force-pushing over history.
    Check: server/tests/test_0611_konstituciya.py::test_n_server_refuses_silently
  2. Changing a team's rules is harder than using them. When the rules ask for two or more signatures, one owner alone cannot lower them or remove a member; a change needs the current signers, or waits 72 hours, and any member can cancel it.
    Check: server/tests/test_0237_team_kvorum.py::test_a_owner_alone_cannot_lower_threshold_or_drop_member, server/tests/test_0237_team_kvorum.py::test_c2_member_cancels_scheduled_change
  3. Nobody confirms their own agent. In a team, once an agent is assigned to the person who runs it, its questions are confirmed by other members, never by that person.
    Check: server/tests/test_0213.py::test_delegated_agent_is_confirmed_by_others_never_by_its_operator, server/tests/test_0237_no_self_approve.py::test_0237_11_team_operator_cannot_approve_own_agent
  4. Trust has an end. “Allow from now on” lasts at most 30 days.
    Check: server/tests/test_kontrakt_konstant.py::test_from_now_on_days
  5. Your data is yours. You export your evidence pack and delete your account without asking us.
    Check: server/tests/test_0224_critique.py::test_0224_b_export_still_verifies, server/tests/test_0223_delete_account.py::test_success_erases_and_nobody_can_come_back
  6. If we are gone, the server is open and your receipts keep checking. The server is open source (witness-server, AGPL-3.0) and runs on your own machine with docker compose up; evidence packs are checked offline, without us.
    Check: server/tests_pack/test_solo_pack.py::test_4_solo_pack_valid_without_org_lines, selfhost/e2e_check.py

How this page changes

Any weakening comes only as a new version, announced in advance, never retroactively. Each version keeps its number and date, and a law leaves this page only together with its test.
